# LTE Study — ロボット輸出のためのLTE入門

LTE搭載ロボットを日本からアジア（中国・韓国・台湾・東南アジア・インド）へ輸出するために必要な知識を、図解・インタラクティブな図・クイズで学ぶための教材サイトです。

## 使い方

ビルド不要です。`index.html` をブラウザで開くだけで使えます（インターネット接続も不要）。

```sh
open index.html          # macOS
```

学習進捗・クイズの成績・チェックリストは、ブラウザの localStorage に保存されます（他の人とは共有されません）。

## 構成

| PART | 章 | 内容 |
|---|---|---|
| I 仕組みを知る | 01 無線通信の基礎 | 電波・周波数・変調、Wi-Fi/Bluetooth/LTEの違い |
| | 02 LTEネットワークの全体像 | 端末・基地局・コア網、APN、MNO/MVNO |
| | 03 接続の流れ | 電源ONからデータ通信までのシーケンス |
| II 技術要素を知る | 04 周波数バンドとFDD/TDD | バンドの読み方、国ごとの違い |
| | 05 LTEカテゴリとIoT向け規格 | Cat-1/Cat-4/LTE-M/NB-IoT/5G RedCap の比較 |
| | 06 ハードウェア構成 | モジュール、アンテナ、SIM、電源の設計ポイント |
| | 07 SIMの種類と回線 | 物理SIM/チップSIM/eSIM、ローカル回線とローミング |
| | 08 ソフトウェアと制御 | ATコマンド、ホスト接続方式、FOTA |
| III 輸出と認証 | 09 規格と認証の全体像 | 3GPP、GCF/PTCRB、技適、キャリア認証 |
| | 10 アジア各国の認証とバンド | 国別の認証制度と主要バンド |
| | 11 国ごとの部品共通化戦略 | 1SKUで何か国に出せるか |
| IV 開発の進め方 | 12 試作から量産までのロードマップ | EVT/DVT/PVT、認証、量産、運用 |

ツール：

- `tools/band-checker.html` — 輸出先を選ぶと必要バンドとモジュールの対応状況を表示
- `tools/module-selector.html` — 用途を答えると推奨LTEカテゴリを提示
- `tools/roadmap.html` — 試作→量産の工程をガントチャートで表示
- `glossary.html` 用語集 / `quiz.html` 総合クイズ

## ディレクトリ

```
index.html, glossary.html, quiz.html
chapters/        各章のページ
tools/           インタラクティブツール
assets/style.css 共通スタイル（ライト/ダーク対応）
assets/app.js    共通スクリプト（ナビ・進捗・図・クイズのエンジン）
assets/data/     バンド・ロードマップ・クイズのデータ
```

章の追加・修正の方法は [AUTHORING.md](AUTHORING.md) を参照してください。

周波数バンド、各国の認証制度、キャリアのサービス状況は頻繁に変わります。各ページの出典と確認日を参照し、実際の製品開発では最新の公式情報・認証代行会社・モジュールベンダーに必ず確認してください。本教材は学習用の概説であり、法的助言ではありません。
